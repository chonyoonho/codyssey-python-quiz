# AI·업무 자동화 퀴즈 게임

터미널에서 즐기는 **파이썬 콘솔 퀴즈 게임**입니다.
퀴즈를 풀고, 직접 퀴즈를 추가하고, 최고 점수를 기록할 수 있으며
**프로그램을 껐다 켜도 추가한 퀴즈와 최고 점수가 그대로 유지**됩니다.

## 1. 프로젝트 개요

- 파이썬 기초(변수, 자료형, 조건문, 반복문, 함수), 클래스, 파일 입출력(JSON), Git/GitHub 사용법을 한 번에 연습하기 위한 학습용 프로젝트입니다.
- 외부 라이브러리 없이 **파이썬 표준 라이브러리만** 사용합니다.
- 클래스 2개로 역할을 나눴습니다.
  - `Quiz` : 퀴즈 한 문제(문제, 선택지 4개, 정답 번호)를 표현
  - `QuizGame` : 메뉴, 퀴즈 풀기/추가/목록/점수, 파일 저장·불러오기 등 게임 전체를 관리

## 2. 퀴즈 주제와 선정 이유

**주제: AI와 업무 자동화 기초 용어** (LLM, 프롬프트, API, JSON, 환각, Git, 스케줄링 등)

선정 이유:

- AI 기술과 업무 자동화를 공부하고 관련 콘텐츠를 만드는 사람이라면 누구나 자주 마주치는 용어라서, 퀴즈로 복습하면 실제로 도움이 됩니다.
- 이 프로젝트에서 직접 쓰는 개념(JSON 저장, Git 버전 관리)이 퀴즈 내용과 겹쳐서, 만들면서 배우고 풀면서 복습할 수 있습니다.
- 정답이 비교적 명확한 기초 용어 위주라 초보자도 퀴즈를 만들고 추가하기 쉽습니다.

기본 퀴즈는 8개이며, 메뉴의 `퀴즈 추가`로 얼마든지 늘릴 수 있습니다.

## 3. 실행 방법

필요한 것: **Python 3.8 이상** (추가 설치 없음, Python 3.13에서 개발·테스트)

```bash
# 1) 저장소 내려받기
git clone https://github.com/chonyoonho/codyssey-python-quiz.git
cd codyssey-python-quiz

# 2) 게임 실행
python main.py        # macOS/Linux에서 python이 없다면 python3 main.py

# 3) (선택) 자동 테스트 실행
python -m unittest discover -s tests -v
```

실행 화면 예시:

```text
====================================
     AI·업무 자동화 퀴즈 게임
====================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
------------------------------------
메뉴 번호를 선택하세요 (1~5):
```

## 4. 기능 목록

| 메뉴 | 기능 | 설명 |
| --- | --- | --- |
| 1 | 퀴즈 풀기 | 저장된 퀴즈를 차례로 출제하고 정답/오답을 알려 줍니다. 모두 풀면 정답 수와 100점 만점 점수를 보여 주고, 최고 점수와 비교해 갱신합니다. 퀴즈가 없으면 안내 메시지를 보여 줍니다. |
| 2 | 퀴즈 추가 | 문제, 선택지 4개, 정답 번호를 입력받아 등록하고 바로 `state.json`에 저장합니다. |
| 3 | 퀴즈 목록 | 저장된 퀴즈를 번호, 문제, 정답과 함께 보여 줍니다. 퀴즈가 없으면 안내합니다. |
| 4 | 점수 확인 | 최고 점수를 보여 줍니다. 아직 퀴즈를 풀지 않았다면 안내합니다. |
| 5 | 종료 | 데이터를 저장하고 프로그램을 끝냅니다. |

### 입력·예외 처리

| 상황 | 동작 |
| --- | --- |
| 입력 앞뒤 공백 (`" 1 "`) | 공백을 지우고 처리합니다. |
| 숫자가 아닌 입력 (`abc`) | 안내 후 다시 입력받습니다. |
| 범위 밖 숫자 (메뉴 `9`, 정답 `0`) | 안내 후 다시 입력받습니다. |
| 빈 입력 (그냥 Enter) | 안내 후 다시 입력받습니다. |
| `Ctrl+C` 또는 입력 스트림 종료(EOF) | 오류 화면 없이 안내 메시지를 보여 주고, 저장 후 안전하게 종료합니다. |
| `state.json`이 없음 (첫 실행) | 기본 퀴즈 데이터로 시작합니다. |
| `state.json`이 손상됨 | 안내 메시지를 보여 주고 기본 퀴즈로 복구합니다. 손상된 파일은 `state.json.broken`으로 보관합니다. |
| 저장/읽기 중 오류 | `try/except`로 처리하여 프로그램이 멈추지 않습니다. |

## 5. 파일 구조

```text
codyssey-python-quiz/
├── main.py              # 프로그램 시작점 (QuizGame을 만들어 실행)
├── game.py              # QuizGame 클래스: 메뉴, 게임 진행, 파일 저장/불러오기
├── quiz.py              # Quiz 클래스: 퀴즈 한 문제 (출력, 정답 확인, 딕셔너리 변환)
├── default_quizzes.py   # 처음 실행할 때 쓰는 기본 퀴즈 8개
├── input_utils.py       # 안전한 입력 함수 (read_int, read_text)
├── tests/
│   └── test_quiz_game.py  # 자동 테스트 (unittest)
├── state.json           # 실행하면 생기는 데이터 파일 (Git에는 올리지 않음)
├── .gitignore
└── README.md
```

## 6. 데이터 파일 설명 (`state.json`)

| 항목 | 내용 |
| --- | --- |
| 경로 | 프로젝트 루트의 `state.json` (`main.py`와 같은 폴더) |
| 인코딩 | UTF-8 (한글이 `\uXXXX` 코드가 아닌 글자 그대로 저장됨) |
| 역할 | 사용자가 추가한 퀴즈와 최고 점수를 저장해, 프로그램을 다시 실행해도 유지되게 합니다. |
| 생성 시점 | 퀴즈 추가, 최고 점수 갱신, 프로그램 종료 시 자동 저장 |
| Git 관리 | 개인 데이터이므로 `.gitignore`로 제외했습니다. 없으면 기본 퀴즈로 시작합니다. |

스키마(데이터 모양):

```json
{
  "quizzes": [
    {
      "question": "AI에게 원하는 결과를 얻기 위해 입력하는 지시문을 무엇이라고 부를까요?",
      "choices": ["프롬프트", "커밋", "쿠키", "컴파일"],
      "answer": 1
    }
  ],
  "best_score": 100
}
```

| 키 | 타입 | 설명 |
| --- | --- | --- |
| `quizzes` | list | 퀴즈 목록. 비어 있어도 됩니다. |
| `quizzes[].question` | str | 문제 (빈 문자열 불가) |
| `quizzes[].choices` | list of str | 선택지 4개 |
| `quizzes[].answer` | int | 정답 번호 (1~4) |
| `best_score` | int 또는 null | 100점 만점 최고 점수. 아직 퀴즈를 풀지 않았다면 `null` |

점수는 `정답 수 ÷ 전체 문제 수 × 100`을 반올림한 값입니다. 문제 수가 달라져도 비교할 수 있도록 100점 만점으로 환산합니다.
