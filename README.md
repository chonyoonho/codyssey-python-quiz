# AI·업무 자동화 퀴즈 게임

터미널에서 즐기는 **파이썬 콘솔 퀴즈 게임**입니다.
퀴즈를 풀고, 직접 퀴즈를 추가·삭제하고, 점수를 기록할 수 있으며
**프로그램을 껐다 켜도 추가한 퀴즈와 최고 점수, 풀이 기록이 그대로 유지**됩니다.

## 1. 프로젝트 개요

- 파이썬 기초(변수, 자료형, 조건문, 반복문, 함수), 클래스, 파일 입출력(JSON), Git/GitHub 사용법을 한 번에 연습하기 위한 학습용 프로젝트입니다.
- 외부 라이브러리 없이 **파이썬 표준 라이브러리만** 사용합니다. (`json`, `random`, `datetime`, `pathlib` 등)
- 클래스 2개로 역할을 나눴습니다.
  - `Quiz` : 퀴즈 한 문제(문제, 선택지 4개, 정답 번호, 힌트)를 표현
  - `QuizGame` : 메뉴, 퀴즈 풀기/추가/목록/삭제/점수, 파일 저장·불러오기 등 게임 전체를 관리
- 선택 과제(보너스)인 **랜덤 출제, 문제 수 선택, 힌트, 퀴즈 삭제, 점수 기록 히스토리**까지 구현했습니다.

## 2. 퀴즈 주제와 선정 이유

**주제: AI와 업무 자동화 기초 용어** (LLM, 프롬프트, API, JSON, 환각, Git, 스케줄링 등)

선정 이유:

- AI 기술과 업무 자동화를 공부하고 관련 콘텐츠를 만드는 사람이라면 누구나 자주 마주치는 용어라서, 퀴즈로 복습하면 실제로 도움이 됩니다.
- 이 프로젝트에서 직접 쓰는 개념(JSON 저장, Git 버전 관리)이 퀴즈 내용과 겹쳐서, 만들면서 배우고 풀면서 복습할 수 있습니다.
- 정답이 비교적 명확한 기초 용어 위주라 초보자도 퀴즈를 만들고 추가하기 쉽습니다.

기본 퀴즈는 8개이며(각각 힌트 포함), 메뉴의 `퀴즈 추가`로 얼마든지 늘릴 수 있습니다.

## 3. 실행 방법

필요한 것: **Python 3.10 이상** (추가 설치 없음, Python 3.13에서 개발·테스트)

```bash
# 1) 저장소 내려받기
git clone https://github.com/chonyoonho/codyssey-python-quiz.git
cd codyssey-python-quiz

# 2) 게임 실행
python main.py        # macOS/Linux에서 python이 없다면 python3 main.py

# 3) (선택) 자동 테스트 실행
python -m unittest discover -s tests -v
```

실행 화면 예시:

```text

  3) Excel

```

## 4. 기능 목록

| 메뉴 | 기능 | 설명 |
| --- | --- | --- |
| 1 | 퀴즈 풀기 | 풀 문제 수를 고르면 그만큼을 **무작위 순서**로 출제하고 정답/오답을 알려 줍니다. 힌트가 있는 문제는 `h`를 입력해 힌트를 볼 수 있습니다. 모두 풀면 정답 수와 100점 만점 점수를 보여 주고, 최고 점수와 비교해 갱신합니다. 퀴즈가 없으면 안내 메시지를 보여 줍니다. |
| 2 | 퀴즈 추가 | 문제, 선택지 4개, 정답 번호, 힌트(선택)를 입력받아 등록하고 바로 `state.json`에 저장합니다. |
| 3 | 퀴즈 목록 / 삭제 | 저장된 퀴즈를 번호, 문제, 정답, 힌트와 함께 보여 줍니다. 이어서 번호를 골라 퀴즈를 삭제할 수 있고(`0`이면 삭제 안 함), 삭제 결과는 바로 파일에 반영됩니다. 퀴즈가 없으면 안내합니다. |
| 4 | 점수 확인 | 최고 점수와 **최근 풀이 기록 5회**(날짜/시간, 푼 문제 수, 정답 수, 힌트 사용, 점수)를 보여 줍니다. 아직 퀴즈를 풀지 않았다면 안내합니다. |
| 5 | 종료 | 데이터를 저장하고 프로그램을 끝냅니다. |

### 점수 계산과 힌트 차감

- 문제당 최대 1점이며, 점수는 `인정받은 점수 ÷ 푼 문제 수 × 100`을 반올림한 100점 만점 값입니다.
- 힌트를 보고 맞힌 문제는 **절반(0.5점)**만 인정됩니다. 같은 문제에서 힌트를 여러 번 봐도 한 번으로 계산하며, 틀리면 0점입니다.
- 예) 2문제 중 2문제 정답, 그중 1문제는 힌트 사용 → (0.5 + 1) ÷ 2 × 100 = **75점**

### 입력·예외 처리

| 상황 | 동작 |
| --- | --- |
| 입력 앞뒤 공백 (`" 1 "`) | 공백을 지우고 처리합니다. |
| 숫자가 아닌 입력 (`abc`) | 안내 후 다시 입력받습니다. |
| 범위 밖 숫자 (메뉴 `9`, 정답 `0`) | 안내 후 다시 입력받습니다. |
| 빈 입력 (그냥 Enter) | 안내 후 다시 입력받습니다. (힌트처럼 선택 입력은 Enter로 건너뜀) |
| `Ctrl+C` 또는 입력 스트림 종료(EOF) | 오류 화면 없이 안내 메시지를 보여 주고, 저장 후 안전하게 종료합니다. |
| `state.json`이 없음 (첫 실행) | 기본 퀴즈 데이터로 시작합니다. |
| `state.json`이 손상됨 | 안내 메시지를 보여 주고 기본 퀴즈로 복구합니다. 손상된 파일은 `state.json.broken`으로 보관합니다. |
| 저장/읽기 중 오류 | `try/except`로 처리하여 프로그램이 멈추지 않습니다. |

## 5. 파일 구조

```text
codyssey-python-quiz/
├── main.py              # 프로그램 시작점 (QuizGame을 만들어 실행)
├── game.py              # QuizGame 클래스: 메뉴, 게임 진행, 파일 저장/불러오기
├── quiz.py              # Quiz 클래스: 퀴즈 한 문제 (출력, 정답 확인, 딕셔너리 변환)
├── default_quizzes.py   # 처음 실행할 때 쓰는 기본 퀴즈 8개
├── input_utils.py       # 안전한 입력 함수 (read_int, read_text)
├── tests/
│   └── test_quiz_game.py  # 자동 테스트 (unittest)
├── state.json           # 실행하면 생기는 데이터 파일 (Git에는 올리지 않음)
├── .gitignore
└── README.md
```

## 6. 데이터 파일 설명 (`state.json`)

| 항목 | 내용 |
| --- | --- |
| 경로 | 프로젝트 루트의 `state.json` (`main.py`와 같은 폴더) |
| 인코딩 | UTF-8 (한글이 `\uXXXX` 코드가 아닌 글자 그대로 저장됨) |
| 역할 | 퀴즈 목록, 최고 점수, 풀이 기록을 저장해 프로그램을 다시 실행해도 유지되게 합니다. |
| 생성 시점 | 퀴즈 추가·삭제, 퀴즈 풀이 종료, 프로그램 종료 시 자동 저장 |
| Git 관리 | 개인 데이터이므로 `.gitignore`로 제외했습니다. 없으면 기본 퀴즈로 시작합니다. |
| 옛 형식 호환 | `hint`나 `history`가 없는 이전 버전의 파일도 그대로 읽을 수 있습니다. |

스키마(데이터 모양):

```json
{
  "quizzes": [
    {
      "question": "AI에게 원하는 결과를 얻기 위해 입력하는 지시문을 무엇이라고 부를까요?",
      "choices": ["프롬프트", "커밋", "쿠키", "컴파일"],
      "answer": 1,
      "hint": "AI에게 '이렇게 해 줘'라고 시키는 말을 가리킵니다."
    }
  ],
  "best_score": 75,
  "history": [
    {
      "played_at": "2026-11-10 19:40:12",
      "total": 2,
      "correct": 2,
      "hints_used": 1,
      "score": 75
    }
  ]
}
```

| 키 | 타입 | 설명 |
| --- | --- | --- |
| `quizzes` | list | 퀴즈 목록. 비어 있어도 됩니다. |
| `quizzes[].question` | str | 문제 (빈 문자열 불가) |
| `quizzes[].choices` | list of str | 선택지 4개 |
| `quizzes[].answer` | int | 정답 번호 (1~4) |
| `quizzes[].hint` | str | 힌트. 없으면 빈 문자열(`""`) |
| `best_score` | int 또는 null | 100점 만점 최고 점수. 아직 퀴즈를 풀지 않았다면 `null` |
| `history` | list | 지금까지 푼 모든 게임 기록 (오래된 것이 앞) |
| `history[].played_at` | str | 게임을 마친 날짜/시간 (`YYYY-MM-DD HH:MM:SS`) |
| `history[].total` | int | 푼 문제 수 |
| `history[].correct` | int | 맞힌 문제 수 |
| `history[].hints_used` | int | 힌트를 본 문제 수 |
| `history[].score` | int | 그 게임의 점수 (0~100) |

## 7. 보너스 과제 구현 내용

| 보너스 | 구현 |
| --- | --- |
| 랜덤 출제 | `random.sample`로 퀴즈를 무작위 순서로 뽑아 출제 |
| 문제 수 선택 | 퀴즈 풀기 시작 때 1~(전체 퀴즈 수) 중에서 풀 문제 수를 선택 |
| 힌트 기능 | `Quiz.hint` 속성 추가, 풀이 중 `h`로 힌트 보기, 힌트를 쓰고 맞힌 문제는 절반 점수 |
| 퀴즈 삭제 | 퀴즈 목록 화면에서 번호로 삭제(확인 후), 삭제 즉시 `state.json`에 반영 |
| 점수 기록 히스토리 | 모든 게임의 날짜/시간, 푼 문제 수, 점수를 저장하고 점수 확인 화면에서 최근 5회를 표시 |

## 8. Git 작업 흐름

기능 하나를 끝낼 때마다 커밋했습니다. `퀴즈 풀기`는 `feature/play-quiz`, 보너스 과제는 `feature/bonus` 브랜치에서 작업한 뒤 `main`에 병합했습니다.

```text
git log --oneline --graph
```

clone/pull 실습: 저장소를 별도 폴더에 `git clone`한 뒤 이 줄을 추가해 push했고, 원래 작업 폴더에서 `git pull`로 가져왔습니다.
